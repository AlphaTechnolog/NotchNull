# NotchNull 1.5.3

- Show the actual reset countdown when a quota window is exhausted. Previously,
  the pace prediction displayed a warning with “now”, obscuring the reset time.
- Do not predict exhaustion for expired windows.
- Preserve newer Claude quota observations when an older MendCode export is read.
  Original observation timestamps determine ordering; rewriting a file does not
  make the quota reading newer.

Retains the published 1.5.1 account-limit fixes and 1.5.2 performance maintenance.
No credential handling, provider requests or refresh-frequency changes.
