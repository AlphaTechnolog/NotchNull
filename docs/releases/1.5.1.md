# NotchNull 1.5.1

- Recover Codex quota readings after a failed request with a short, bounded retry delay instead of waiting ten minutes. Successful readings retain the ten-minute cadence and refresh when a reported window resets.
- Show the OpenCode usage block only when OpenCode Go limits have been confirmed. Installing or using free OpenCode no longer adds an empty quota block or a database error to the usage panel; session monitoring stays available.
