# NotchNull 1.5.2

## Changes

- Read large agent transcript lines incrementally without repeatedly scanning the
  accumulated buffer. Reuse directory metadata with filesystem invalidation and a
  bounded fallback, and avoid overlapping monitor polls.
- Stop system statistics when Home is not visible. Track consumers independently
  per window instead of counting view appearance callbacks.
- Query disk capacity off the main thread without overlapping requests.
- Poll tracked download partials instead of rescanning all completed downloads.
  Preserve stalled-download resumption, Firefox placeholders and completion events.
- Deduplicate unchanged media playback projections and artwork, and reuse player
  identity. Keep pause, seek and metadata updates observable.
- Pause hidden media timelines and stop hidden indicator pulse animations while
  retaining the existing visible transitions and animation cadence.

## Known limitations

This is a targeted maintenance release, not a complete CPU or memory fix.
Live testing still observed approximately 23% CPU with a collapsed agent activity.
An approximately 1.5 GiB startup footprint peak remains unattributed; the footprint
later fell to approximately 124 MiB. These measurements are state-dependent, not
a controlled before/after improvement claim. SwiftUI/CoreAnimation work remains
under investigation. Physical multi-display behavior has not been validated.

Includes regression coverage for transcript boundaries, metadata invalidation,
statistics ownership, download progress/completion and media deduplication.
